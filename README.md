# 🏰 إمتلاك (Emtilak) — نظام إدارة العقارات السكنية وتتبع الإيجارات

تطبيق Android و iOS مخصص لمالكي ومديري العقارات السكنية والتجارية، يعتمد على مبدأ **Offline-First** ويوفر واجهة مستخدم حديثة باللغة العربية (RTL) لإدارة المباني، الوحدات، العقود، المستأجرين، الدفعات المالية، والتقارير.

## ⚡ الميزات والخصائص الرئيسية

1. **التعريف بالبرنامج (Onboarding)**:
   - شاشة تعريفية ثلاثية التمرير تستخدم `introduction_screen ^4.0.0`.
   - تُعرض لمرة واحدة فقط عند أول فتح للتطبيق بحفظ الحالة في `SharedPreferences`.

2. **لوحة التحكم المباشرة (Dashboard)**:
   - عرض إجمالي التدفق المالي مع نسبة التغير عن الشهر الماضي.
   - بطاقات إحصائية تفاعلية: (المباني، الوحدات، المؤجرة، الفارغة).
   - رسم دائري توضيحي لنسبة التحصيل (مدفوع، متأخر، قيد التحصيل).
   - وصول سريع لـ "تسجيل دفعة" و "عقد جديد".

3. **إدارة المباني والشبكة البصرية للوحدات (Properties & Visual Grid)**:
   - إضافة مباني جديدة وتحديد عنوانها وعدد وحداتها.
   - عند الضغط على أي مبنى يفتح شبكة الوحدات الملونة الخاصة بـ **ذلك المبنى تحديداً**.
   - كروت الوحدات ملونة تلقائياً بحسب حالتها (مؤجرة، فارغة، صيانة، قيد التجهيز).
   - الضغط على أي وحدة يفتح خياراتها (عرض التفاصيل، كشف الحساب، أو تسجيل صيانة).

4. **العقود والمستأجرون (Contracts & Tenants)**:
   - إضافة عقد جديد مع ربط المستأجر والوحدة وقيمة الإيجار والعملة وتاريخ البداية والنهاية.
   - الضغط على أي عقد يفتح BottomSheet يستعرض كافة التفاصيل والخيارات السريعة.
   - كشف حساب تفصيلي لكل مستأجر يستعرض حركة السحوبات والدفعات مع إمكانية التصدير إلى PDF.

5. **المعاملات المالية والتقارير (Transactions & Reports)**:
   - فلترة المدفوعات التفاعلية بحسب (الكل / مدفوع / متأخر / جزئي).
   - تسجيل دفعة جديدة وطباعة / مشاركة سند القبض.
   - اختيار تواريخ حقيقي عبر `DateRangePicker` لتصفية تقرير الأرباح والخسائر.

6. **إدارة العملات والإعدادات (Currencies & Settings)**:
   - إدارة العملات الأجنبية وتحديد العملة الأساسية وإدخال أسعار الصرف.
   - إعدادات النسخ الاحتياطي تلقائياً/يدوياً إلى Google Drive.
   - تغيير كلمة المرور وتفعيل التنبيهات.

## 🚀 تشغيل المشروع

### المتطلبات الأساسية
- Flutter SDK `^3.9.2` أو أحدث.
- Android Studio / VS Code.

### الخطوات
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-username/emtilak.git

# 2. الانتقال إلى فرع التطوير
git checkout develop

# 3. تثبيت الباقات
flutter pub get

# 4. تشغيل التطبيق
flutter run
```

## 🌳 شجرة الفروع وتاريخ التغييرات (Git Workflow)

يعتمد المشروع على نظام الفروع الاحترافي Git Flow:

- **`main`**: فرع الإصدارات المستقرة.
- **`develop`**: الفرع الأساسي المدمج للتطوير.
- **الفروع الفرعية للميزات**:
  - `feature/splash-and-onboarding`: الشاشة الافتتاحية وشاشة Onboarding.
  - `feature/auth-page`: شاشة تسجيل الدخول.
  - `feature/app-layout-and-navigation`: الهيكل الرئيسي والـ Drawer والـ Routes.
  - `feature/dashboard-and-properties`: لوحة التحكم والمباني والشبكة البصرية للوحدات.
  - `feature/contracts-and-financials`: نماذج العقود والمدفوعات والصيانة والتقارير.
  - `feature/tenants-and-settings`: شاشة المستأجرين وكشف الحساب والعملات والإعدادات.
